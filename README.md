📊 Production Dashboard – Excel Project
📌 Project Overview

This project is an interactive Production Dashboard built using Microsoft Excel.
It showcases my skills in data cleaning, pivot tables, slicers, pivot charts, and dashboard design to analyze production costs and task distribution across managers.

The dashboard allows users to filter data dynamically by region, gender, age group, and production quarter to gain meaningful insights.

🛠 Tools & Technologies Used

Microsoft Excel

Pivot Tables

Pivot Charts

Slicers

Excel Functions

Data Cleaning Techniques

📂 Dataset Description

The dataset includes production-related information such as:

Product Type

Production Cost

Manager Names

Number of Tasks

Region

Gender

Age Groups

Production Date / Quarters

🧹 Data Cleaning Process

The following data cleaning steps were performed before analysis:

Removed duplicate records

Handled missing and inconsistent values

Standardized category names (region, gender, age groups)

Converted date fields into quarters

Ensured correct data types for numerical and categorical fields

📊 Data Analysis Using Pivot Tables

Multiple pivot tables were created to analyze:

Total production cost by product type

Number of tasks assigned to each manager

Production performance across regions and quarters

Demographic-based filtering using slicers

📈 Dashboard Features

The Excel dashboard includes:

Interactive slicers for Region, Gender, Age Group, and Quarter

Column chart showing Total Production Cost by Product Type

Horizontal bar chart showing Number of Tasks by Manager

Clean and professional dashboard layout

Dynamic updates based on slicer selection
